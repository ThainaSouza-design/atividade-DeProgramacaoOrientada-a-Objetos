# 📝 Exercícios de Programação Orientada a Objetos (POO) em JavaScript

Este repositório reúne a resolução de dois exercícios práticos desenvolvidos para reforçar os principais conceitos de **Programação Orientada a Objetos (POO)** utilizando **JavaScript**.

O objetivo da atividade foi aplicar conceitos fundamentais como criação de classes, herança, encapsulamento, sobrescrita de métodos e manipulação de objetos, simulando situações do mundo real.

## 📚 Conteúdo desenvolvido

### 👨‍💼 Exercício 1 – Sistema de Funcionários

Foi desenvolvido um sistema para cadastro de funcionários de uma empresa.

### Funcionalidades

* Cadastro de funcionários.
* Apresentação dos dados de cada funcionário.
* Cálculo de bônus.
* Visualização do salário.
* Aumento de salário.
* Especialização de funcionários por meio de herança.

### Classes criadas

* `Funcionario`
* `Desenvolvedor`
* `Designer`

### Conceitos aplicados

* Classes (`class`)
* Construtor (`constructor`)
* Métodos
* Herança (`extends`)
* Sobrescrita de métodos (Polimorfismo)
* Atributos privados (`#`)
* Criação de objetos utilizando `new`

---

## 🚗 Exercício 2 – Sistema de Locadora de Veículos

Foi desenvolvido um sistema simples para gerenciamento de uma locadora de veículos.

### Funcionalidades

* Cadastro de veículos.
* Listagem de veículos disponíveis.
* Cálculo do valor do aluguel.
* Cálculo do total arrecadado pela locadora.
* Gerenciamento dos veículos cadastrados.

### Classes criadas

* `Veiculo`
* `Carro`
* `Moto`
* `Locadora`

### Funcionalidades extras

* Cálculo personalizado do aluguel para carros.
* Cálculo personalizado do aluguel para motos.
* Armazenamento dos veículos em um array.
* Método para adicionar veículos.
* Método para listar veículos.
* Método para calcular o total do aluguel.
* **Desafio extra:** remoção de veículos pelo modelo.
